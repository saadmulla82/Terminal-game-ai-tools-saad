# 🕵️ Secret Agent Hacker Terminal: Hack the Matrix, Crack the Code!

## About
This is a retro hacker-style terminal web app that I made for the AI Coding Lab. It has a green falling-code Matrix background, a neon dark UI, and a few fake hacking tools. There is also a hidden cipher mini-game. Created by Student #112.

## How to Use
1. Open the live link above in Chrome or Edge.
2. Click the **Scan**, **Decrypt**, or **Upload** buttons.
3. Each button plays a beep sound, fills the progress bar, and prints a message in the terminal log.
4. Watch the log to see the "mission" start and finish.

## 🔐 Secret Features
- **Hidden Cipher Game:** Press **Ctrl + Alt + H** (or click the header) to open the Caesar Cipher Decoder.
- **Hint:** Try decoding `KHOOR` with shift `3` to crack the secret and win!
- **Built-in Tests:** The code has `console.assert()` checks at the bottom. Open the browser Console to see that all tests pass.

## Built With
- HTML, CSS and JavaScript (all in one `index.html` file)
- Canvas for the Matrix rain effect
- Web Audio API for the sound effects
